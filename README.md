## 2. Descripción de la actividad

La actividad FORM-FB-01 tiene como finalidad localizar,
verificar y analizar fuentes académicas relacionadas
con los fundamentos de sistemas distribuidos y las
arquitecturas de microservicios.

Cada integrante elaboró de manera individual cinco
fichas bibliográficas, utilizando publicaciones
científicas del período 2021-2026.

Las fichas incluyen:

- Referencia bibliográfica IEEE mediante BibLaTeX.
- Identificador DOI o ISBN verificado.
- Resumen de investigación de 100 palabras.
- Dato concreto con página o sección.
- Nota personal y aplicación prevista en TA-IND-01.

El trabajo constituye una preparación bibliográfica
para el informe académico individual TA-IND-01.

## 4. Organización del repositorio

Cada integrante dispone de una carpeta independiente
para almacenar los archivos correspondientes a su
actividad FORM-FB-01.

La organización individual contempla:

- Documento PDF compilado.
- Código fuente LaTeX (.tex).
- Archivo bibliográfico (.bib).
- README.md con instrucciones de compilación.
- Fuentes académicas consultadas, cuando su licencia
  permite su redistribución.

Los archivos de cada integrante deben consultarse
desde los enlaces de la sección 3.

---

## 5. Tecnologías utilizadas

- LaTeX para la elaboración de los documentos.
- BibLaTeX con estilo IEEE para las referencias.
- Biber para el procesamiento bibliográfico.
- PDFLaTeX para la compilación.
- Git y GitHub para el control de versiones.
- Visual Studio Code y LaTeX Workshop como
  herramientas de edición, cuando corresponda.

### Compilación

Las instrucciones específicas de compilación se
encuentran en el README individual de cada integrante.

## 6. Consideraciones académicas
